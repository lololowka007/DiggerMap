# DiggerMap

DiggerMap 1.2 для iPhone 16 Pro Max. Схема маршрута по голосовым командам и шагам. Распознавание Whisper Base и словарь включены в IPA: сеть, подписка и русская модель Apple для речи не нужны. LiDAR не используется.

Нажмите «Слушать команды», разрешите микрофон и дождитесь загрузки встроенной модели. Говорите фразами с паузой примерно секунду. Индикатор микрофона показывает поступление звука; услышанный текст и изменение карты видны в нижней панели. В «Журнале» есть полная история, ошибки и кнопка отправки текста журнала.

- «Иду налево сто метров» — поворот налево и участок 100 м.
- «Прошёл около четырёх метров» — участок 4 м.
- «На 12 градусов налево» — изменение направления, видимое по оранжевой стрелке.
- «Прямо 12 шагов» — участок по заданному числу шагов, 0.75 м за шаг.
- «Иду прямо» — начать обновление карты по реальному шагомеру. Разрешите «Движение и фитнес». iPhone сообщает шаги с задержкой.
- «Стоп» — остановить режим шагов.
- «Точка склад», «развилка», «вверх», «вниз», «ширина коридора три метра».

Команды применяются автоматически. Расстояние, названное во время режима шагов, заменяет текущий участок после последней голосовой команды, чтобы не считать его дважды. Запись останавливается кнопкой; карту можно сбросить только после двух подтверждений. Карта и журнал сохраняются локально. Стены обозначают предполагаемые границы коридора с заданной шириной. Барометр показывает изменение высоты; автоматически этаж не меняет.

После отправки исходников GitHub Actions собирает неподписанный `DiggerMap-unsigned.ipa` на macOS. Скачать: Actions → последний Build unsigned IPA → Artifacts. Затем открыть IPA в Sideloadly и подписать своей учётной записью Apple на своём компьютере. Пароль и коды Apple ID никому не передавайте.

Сборка проверяет распознавание записанной русской фразы через тот же преобразователь аудио и выделение фраз, которые использует микрофон. Затем проверяет направление и длину полученного маршрута. Интерфейс снимается в симуляторе iPhone 16 Pro Max. Физический микрофон гарнитуры, шагомер и длительная работа с заблокированным экраном требуют проверки на устройстве.
