# DiggerMap

Первый прототип карты для iPhone 16 Pro Max. Работает без LiDAR и сервера. Человек диктует или вводит перемещения; схема строится по подтверждённым командам. Это черновик маршрута, а не средство безопасной навигации или автоматическое сканирование здания.

Команды: `прямо 12 шагов`, `налево`, `направо`, `направо 45 градусов`, `точка: лестница`, `вверх`, `вниз`. Команды применяются отдельно кнопкой после распознавания, чтобы ошибка речи не попала на карту. Маршрут хранится локально. Барометр отображает изменение высоты отдельно; этаж автоматически не назначается. Компас не используется для линии маршрута, поскольку в металлических помещениях он может ошибаться.

После отправки исходников GitHub Actions собирает неподписанный `DiggerMap-unsigned.ipa` на macOS. Скачать: Actions → последний Build unsigned IPA → Artifacts. Затем открыть IPA в Sideloadly и подписать своей учётной записью Apple на своём компьютере. Пароль и коды Apple ID никому не передавайте.

Системное распознавание включено только в режиме on-device. Если русский язык на телефоне не поддерживает локальную модель, можно вводить команды текстом.
